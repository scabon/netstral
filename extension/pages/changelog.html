Changelog

v0.4.2 — bouton refresh dans la pop-up

Bouton ⟳ à droite de la ligne « lu il y a… » (sous le pourcentage), hors du menu ; l'icône tourne pendant l'actualisation. La ligne source est simplifiée : « lu il y a X min » (la source n'est plus répétée).

v0.4.1 — liens console/admin en bas de la pop-up

Les liens Console Mistral et Abonnement (admin) sont directement en bas de la pop-up (ancres ouvrant un onglet), plus besoin d'ouvrir le menu ⋮.

v0.4.0 — alertes, liens rapides, langue & thème

Notification navigateur quand la consommation franchit un seuil réglable (désactivable) ; liens rapides vers console.mistral.ai et admin.mistral.ai/subscription dans le menu ⋮ de la pop-up et dans les paramètres ; langue (système / FR / EN) et thème (système / clair / sombre) dans les paramètres, appliqués à la pop-up, au side panel, aux options et à la page À propos (i18n embarqué i18n.js, 138 clés fr/en).

v0.3.4 — projection graphique

La projection devient une piste graphique : consommé en couleur (comme le badge), tick rouge à 100 %, zone hachurée au-delà de 100 % quand l'échelle déborde, et marqueur « ~X % » à la fin de période (rouge s'il dépasse 100 %). Lignes de rythme et de jours avant 100 % conservées dessous.

v0.3.3 — une seule carte + projection

Consommation, facturation (crédits PAYG, réinitialisation, type de plan, clé API) et projection sont regroupées dans une seule carte. Projection : rythme actuel en %/jour, % estimé en fin de période (peut dépasser 100 %) et nombre de jours avant 100 % à ce rythme. Période = mois entre deux reset (resetAt connu) ou mois calendaire UTC en repli.

v0.3.2 — pop-up : masquages et « dans X jours »

« Type de plan » masqué tant que la valeur n'est pas reconnue ; ligne BYOK masquée si la clé est configurée, remplacée sinon par un bouton « Configurer la clé API » (ouvre les paramètres) ; sous la date de réinitialisation, affichage « dans X jours » ; le doublon « compte lu il y a… » du bas est supprimé (on garde celui de la ligne de conso).

v0.3.1 — corrections pop-up

Comptage local masqué dès que la conso du compte Mistral est disponible ; dates au format yyyy-MM-dd (UTC) ; le message « connectez-vous » ne s'affiche plus quand une source compte est lue (une sonde du plan qui échoue n'est plus signalée comme une erreur de session) ; classification du plan élargie (free/pro/basic/ team/scale/trial/PAYG/entreprise) avec le brut exposé en debug dans les options.

v0.3.0 — pop-up de l'icône

Le clic sur l'icône ouvre une pop-up : barre de progression de la consommation (même % et couleur que le badge), type de plan du compte Mistral (gratuit / pro / entreprise, lu depuis la session), crédits PAYG restants, réinitialisation, clé API configurée ou non, et usage local du mois. Menu : ouvrir le chat (side panel / sidebar), actualiser, paramètres, changelog, à propos.

v0.2.9 — libellés des options

Nettoyage des libellés de la page d'options après validation.

v0.2.8 — badge sur le plan Vibe

Cartographie complète du BFF admin : billing.budget embarque deux sous-budgets, api_budget (allocation incluse) et vibe_budget (le plan Vibe affiché sur /subscription). Priorité du badge : plan Vibe > allocation API > crédits PAYG > comptage local.

v0.2.2 — support Firefox

Un seul manifest cross-browser : side_panel (Chrome) + sidebar_action (Firefox), service worker + event page, permissions réseau opt-in sur Firefox MV3.

v0.2.1 — usage réel du compte

Le badge lit admin.mistral.ai/api/local-trpc/billing.budget avec le cookie de session Mistral : consommation réelle du compte (tous canaux), rafraîchie toutes les 30 min et après chaque tour.

v0.2 — badge de consommation local

Compteur mensuel des tokens passés par Webstral (champ usage des réponses), badge % avec seuils vert/orange/rouge configurables.

v0.1 — squelette

Extension Manifest V3 : chat Mistral en streaming (SSE) dans le side panel, BYOK (clé API collée dans les options), sélecteur de modèle.
