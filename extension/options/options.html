Webstral

Webstral appelle directement l'API Mistral depuis votre navigateur (BYOK — Bring Your Own Key). Aucune donnée ne transite ailleurs.

Clé API Mistral

Créez une clé sur console.mistral.ai (La Plateforme). Elle reste stockée localement dans l'extension.

Connexion & modèles

    Le modèle par défaut se choisit dans le bandeau du side panel.

    Budget mensuel & badge

    Le badge de l'icône affiche le pourcentage des tokens API consommés ce mois-ci par rapport au budget ci-dessous (comptage local, par mois calendaire).

    À venir

    Badge de consommation de tokens sur l'icône, clé Admin Mistral pour le quota réel, « Ask Webstral » sur sélection de texte, version Firefox.
