Webstral

Webstral appelle directement l'API Mistral depuis votre navigateur (BYOK — Bring Your Own Key). Aucune donnée ne transite ailleurs.

Alertes de consommation

Accès réseau de l'extension

Clé API Mistral

Créez une clé sur console.mistral.ai (La Plateforme). Elle reste stockée localement dans l'extension.

Connexion & modèles

    Le modèle par défaut se choisit dans le bandeau du side panel.

    Usage réel du compte (badge)

    Affiché en priorité sur le badge : la consommation réelle du compte Mistral (tous canaux — API, Studio, Webstral…), lue depuis votre session Mistral dans ce navigateur (connectez-vous sur console.mistral.ai). Aucun mot de passe n'est demandé : l'extension lit le cookie de session existant.
